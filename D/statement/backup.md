{{ s('description') }}

小 L 有一个集合 $S$，初始时 $S_0=\{a,b,c\}$，其中 $a<b<c$ 是三个互不相同的非负整数。

对于 $i\ge 1$，定义

$$
S_i=\left\{x\in \mathbb{Z}~\middle|~ \exists\,u,v\in S_{i-1},\ x=\dfrac{u+v}{2}\right\}.
$$

也就是说，$S_i$ 由 $S_{i-1}$ 中任意两个数（允许相同）的平均值组成。容易看出 $S_{i-1}\subseteq S_i$。

现在有 $q$ 次询问，每次给定一个非负整数 $t$，请你回答：最小的非负整数 $k$，使得 $t\in S_k$；若不存在这样的 $k$，则回答 $-1$。

本题是一道交互题。你不仅需要求出最小的 $k$，还需要向评测程序逐层说明 $t$ 是如何由 $a,b,c$ 通过反复取平均得到的。

**数据范围**：$0\le a<b<c\le 2^{40}$，$0\le t\le 2^{40}$，$1\le q\le 1000$。保证答案（当存在时）不超过 $80$。

{{ s('input format') }}

从标准输入读入数据。第一行包含三个整数 $a,b,c$；第二行包含一个整数 $q$。

{{ s('交互方式') }}

你的程序通过标准输入、标准输出与评测程序交互。请在每次输出后刷新缓冲区（例如 C++ 中的 `std::endl`、`fflush(stdout)`，或 Python 中的 `sys.stdout.flush()`）。

交互流程如下：

1. 首先读入 $a,b,c$ 与 $q$。

2. 评测程序会依次处理 $q$ 个询问。对于每个询问，评测程序先向你的标准输入写入一行，包含一个整数 $t$。随后你需要输出一行作答：

   * 若不存在 $k$，输出 `-1`；
   * 若最小 $k=0$（即 $t\in S_0=\{a,b,c\}$），输出 `0`；
   * 否则，先输出一行一个整数 $k$（你求出的最小 $k$），随后进行 $k$ 轮交互。

3. 记当前正在构造的数为 $v$（初始 $v=t$）。对于第 $k,k-1,\dots,1$ 轮（第 $j$ 轮对应“深度”为 $j$ 的数）：

   * 你需要输出一行两个整数 `x y`，中间用一个空格隔开，表示 $v=\dfrac{x+y}{2}$，即必须满足 $x+y=2v$，并且 $x,y\in S_{j-1}$。
   * 评测程序会从 $x,y$ 中**任选**一个，向你写回一行一个整数（选中的那个数）。你需要读入它，把它作为新的 $v$，继续下一轮。
   * 完成全部 $k$ 轮后，$v$ 一定落在 $S_0$ 中，本询问结束。

评测程序会检查：你输出的 $k$ 是否确实是使 $t\in S_k$ 成立的最小值；每一轮给出的 $x,y$ 是否满足 $x+y=2v$ 且 $x,y\in S_{j-1}$。任何一项检查不通过都会判为错误答案。

对样例：$S_0=\{0,1,7\}$。

* $t=0,1,7$：在 $S_0$ 中，答案为 $0$。
* $t=4$：$4=\dfrac{1+7}{2}\in S_1$，且不在 $S_0$ 中，答案为 $1$。
* $t=2$：$2=\dfrac{0+4}{2}$，其中 $4\in S_1$，所以 $2\in S_2$，答案为 $2$。
* $t=3$：$3=\dfrac{2+4}{2}$，其中 $2,4\in S_2$，所以 $3\in S_3$，答案为 $3$。
* $t=8$：任意 $S_i$ 中的数都不大于 $7$，所以不存在。

对 $t=3$，一种合法的交互是：输出 `3`；输出 `2 4`；若评测程序回 `2`，再输出 `0 4` 并继续；若回 `4`，则输出 `1 7` 并继续。
