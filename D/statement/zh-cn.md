{{ s('description') }}

给定三个互不相同的非负整数 $a,b,c$，小 L 按如下方式定义一系列集合 $S_0,S_1,S_2,\dots$：

- 令 $S_0=\{a,b,c\}$，对于 $i\ge 1$，令 $S_i=\left\{x\in \mathbb{Z}~\middle|~ \exists\,u,v\in S_{i-1},\ x=\frac{u+v}{2}\right\}$。

回答 $q$ 次询问：

- 给定一个非负整数 $t$，求最小的非负整数 $k$，使得 $t\in S_k$；如果答案存在，则你还需要通过 $k$ 轮倒序构造从 $t$ 回归到集合 $S_0$ 中。

{{ s('交互方式') }}

你的程序首先需要读入一行三个非负整数 $a,b,c$ $(0\le a<b<c\le 2^{30})$，代表 $S_0$ 中的元素；

然后，你的程序需要读入一行一个整数 $q$ $(1\le q \le 1000)$，代表询问次数。

接下来 $q$ 次询问，每次询问时你的程序首先需要读入一个非负整数 $t$ $(0\le t \le 2^{30})$，代表目标整数。

如果不存在 $k$ 使得 $t\in S_k$，则输出 `-1`。

否则，你需要先输出一行一个非负整数 $k$，代表最小的 $k$ 使得 $t\in S_k$，然后进行以下交互 $k$ 轮：

- 你需要输出两个非负整数 $u,v$ 使得 $\frac{u+v}{2}=t$，如果这次交互是最后一轮，则你需要保证 $u,v\in S_0$。否则你需要读入一个非负整数 $t_0\in \{u,v\}$，并将 $t$ 的值修改为 $t_0$，然后进行下一轮交互。


**保证每次询问时如果对应的答案 $k$ 存在，则 $k\le 60$。**

{{ s('样例') }}

考虑令 $S_0=\{0,1,7\}$，那么可以得到 $S_1=S_0\cup \{4\}=\{0,1,4,7\},S_2=S_1\cup \{2\}, S_3=S_2\cup \{3\},S_4=S_3\cup \{5\},S_5= S_4\cup \{6\}=S_6=\dots$。

下面会在每行最左侧用 `>` 与 `<` 分别标注你的程序需要读入、输出的内容。**实际交互时不需要也不应该读入、输出这些符号。**

首先你的程序需要读入 $a,b,c$ 与 $q$：

```hide
> 0 1 7
> 4
```

第一次询问 $t=1$，此时 $k=0$：

```hide
> 1
< 0
```

第二次询问 $t=2$，此时 $k=2$，以下是一种可能的交互流程：

```hide
> 2
< 2
< 0 4
> 4
< 1 7
```

第 $1$ 轮交互程序取 $0,4\in S_1$ 使得 $t=2=\frac{0+4}{2}$，交互器选择修改 $t$ 的值为 $4$，然后程序取 $1,7\in S_0$ 使得 $t=\frac{1+7}{2}$。

第三次询问 $t=5$，此时 $k=4$，以下是一种可能的交互流程：

```hide
> 5
< 4
< 3 7
> 3
< 2 4
> 4
< 1 7
> 1
< 1 1
```

注意即使第 $3$ 轮交互结束时 $t\in S_0$，你的程序仍然需要进行第 $4$ 轮交互才能处理下一次询问。

第四次询问 $t=8$，由于对任意非负整数 $i$ 均有 $8\notin S_i$，因此不存在合法的 $k$：

```hide
> 8
< -1
```

所有询问处理完毕，结束程序。
