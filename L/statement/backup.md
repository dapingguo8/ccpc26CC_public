{{ s('description') }}

给定一个长度为 $N$ 的 `01` 序列 $A$。

你可以进行以下的操作任意次（包括零次）：

- 选择 $A$ 的一个长度为偶数的回文子串，将其改写为**一个**字符 `0`，得到新的 $A$。

例如：
    设 $N=5$ 而 $A = \texttt{10011}$。
    你可以选择子串 $\underline{\texttt{1001}}\texttt{1}$ 进行操作，得到 $\texttt{01}$。

求出最终 $A$ 的长度的最小值。

{{ s('input format') }}

{{ self.input_file() }}

**本题有多组测试数据。**

在输入的第一行包含一个正整数 $T$，表示测试数据的组数。

每组数据仅一行，包含一个长度为 $N$ 的 `01` 序列 $A$。

保证 $T \le 10^5$，每组数据满足 $N \ge 1$，且 $\sum N \le 10^6$。

{{ s('output format') }}

{{ self.output_file() }}

输出 $T$ 行，每行一个整数，表示每组数据的答案。
