{{ s('description') }}

有一条长度为 $n$ 的纸带，初始时所有格子都是空白的。小 L 有 $m$ 次染色操作，其中第 $i$ 次操作由一个整数 $o_i$ 与一个位置 $x_i$ 描述：

- 若 $o_i=0$，则将位置区间 $[1,x_i]$ 内的格子改为颜色 $i$；
- 若 $o_i=1$，则将位置区间 $[x_i,n]$ 内的格子改为颜色 $i$。

一个颜色被称为可见的，当且仅当最终纸带上至少有一个格子是这种颜色。

小 L 想让你回答 $q$ 次询问：

- 给出正整数 $l_j,r_j$，假如从空白的纸带开始，只依次执行第 $l_j,l_j+1,\dots,r_j$ 次操作，那么最终纸带上有多少种颜色可见？

{{ s('input format') }}

第一行包含三个整数 $n,m,q$ $(1\le n \le 10^9, 1\le m,q\le 5\times 10^5)$，代表纸带格子数，操作数与询问次数。

接下来 $m$ 行，第 $i$ 行包含两个整数 $o_i,x_i$ $(o_i\in \{0,1\}, 1\le x_i\le n)$，描述第 $i$ 次操作。

接下来 $q$ 行，第 $j$ 行包含两个整数 $l_j,r_j$ $(1\le l_j\le r_j\le m)$，描述第 $j$ 个询问。

{{ s('output format') }}

输出 $q$ 行，每行一个整数，其中第 $j$ 行表示第 $j$ 个询问的答案。

{{ self.sample_text() }}

{{ self.title_sample_description() }}

四次操作里，操作 $1$ 把 $[1,3]$ 染成颜色 $1$，操作 $2$ 把 $[2,5]$ 染成颜色 $2$，操作 $3$ 把整条纸带染成颜色 $3$，操作 $4$ 把 $[4,5]$ 染成颜色 $4$。

- 只执行操作 $1\sim 4$：最终纸带 $[1,3]$ 为颜色 $3$，$[4,5]$ 颜色 $4$。可见颜色为 $3,4$，答案为 $2$。
- 只执行操作 $2\sim 3$：操作 $3$ 覆盖了整条纸带，最终只有颜色 $3$ 可见，答案为 $1$。
- 只执行操作 $1\sim 2$：最终格子 $1$ 为颜色 $1$、格子 $[2,5 ]$ 为颜色 $2$，答案为 $2$。
