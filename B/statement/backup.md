{{ s('background') }}

O5 是 T 大学的一名本科生，他正在为本学期选课发愁。

{{ s('description') }}

T 大学的一周有 $n$ 天，每天有 $m$ 节课。O5 的培养方案构成一棵有 $N+H+1$ 个节点的有根树，其中根节点编号为 $0$，代表整个培养方案；$N$ 个非叶子非根的节点，编号从 $1$ 到 $N$，代表课程模块，每个课程模块有一个具体程度 $q_i$；$H$ 个叶子节点，编号从 $N+1$ 到 $N+H$，代表具体课程。第 $i$ 门课程对应编号为 $N+i$ 的节点，其有 $l_i$ 个可选的上课时间 $(d_{i,j},t_{i,j})$（分别表示一周的哪一天和一天的哪一节课），只需选择其中一个就完成了这门课。由于越往下的模块越具体，所以对任意不为叶子不为根的节点 $a\;(1\leq a\leq N)$，都有 $q_a\geq q_{fa_a}$，这里 $fa_a$ 表示 $a$ 的父节点，且规定 $q_0=0$。同时 T 大学要求不允许叠课，也就是同一个上课时间里至多有一门课。

对于任意不同的两门课，记其对应树上编号为 $i,j$ 的节点，则其相似程度定义为 $q_{lca(i,j)}$，这里 $lca(i,j)$ 表示 $i,j$ 的最近公共祖先，也就是树上深度最大的同时是 $i,j$ 的祖先的那个节点。

O5 需要恰好选择 $K$ 门课。若无法选出 $K$ 门课则输出 $-1$，否则他希望任意两门不同的课之间的相似程度之和最小，也就是记选的课对应树上编号为 $c_1,\cdots,c_K$，需要最小化 $\sum_{1\leq i<j\leq K} q_{lca(c_i,c_j)}$。

$2\leq K\leq 10^3,1\leq nm,N,H,l_i,\sum l_i\leq 10^4,0\leq q_i\leq 10^9,1\leq d_{i,j}\leq n,1\leq t_{i,j}\leq m,0\leq fa_i\leq N$

{{ s('input format') }}

{{ self.input_file() }}

第一行输入五个正整数 $n,m,N,H,K$，含义见题目描述。

接下来一行输入 $N+H$ 个整数 $fa_1,\cdots,fa_{N+H}$，表示对应节点的父节点。

接下来一行输入 $N$ 个整数 $q_1,\cdots,q_N$，表示课程模块具体程度。

接下来 $H$ 行，第 $i$ 行表述第 $i$ 门课程。每行先输入一个正整数 $l_i$，表示这门课程的上课时间数量；接下来输入 $2l_i$ 个正整数 $d_{i,1},t_{i,1},d_{i,2},t_{i,2},\cdots,d_{i,l_i},t_{i,l_i}$，表示具体的上课时间。

{{ s('output format') }}

{{ self.output_file() }}

输出一个整数，无解时输出 $-1$，否则输出题目所要求的两两相似程度之和的最小值。
