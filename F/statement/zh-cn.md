{{ s('description') }}

对一个 $1 \sim n$ 的排列 $p_1, p_2, \dots, p_n$，定义**删除过程**为进行 $10^{100}$ 轮如下操作：

- 对每个非两端的，且当前未被删除的位置 $i$，记 $l,r$ 分别为 $i$ 左右两侧最近的未被删除的位置。若 $p_i<p_l$ 与 $p_i<p_r$ 同时成立，则标记位置 $i$ 为黑色，否则标记位置 $i$ 为白色。

- 所有位置标记完毕后，同时删除所有被标记为黑色的位置，然后清除所有标记。删除一个位置不改变其他位置的下标。

给定 $a_1, a_2, \dots, a_n$，Ecrade_ 想求出满足如下条件的 $1 \sim n$ 的排列 $p_1, p_2, \dots, p_n$ 的数量：

- 对 $p_1,\dots,p_n$ 进行**删除过程**后，若 $a_i \neq -1$，则 $b_i = a_i$，其中 $b_i$ 表示位置 $i$ 被删除时所在的轮数，始终未被删除的位置记为 $b_i = 0$。

由于答案可能很大，请对 $10^9 + 7$ 取模。

一个长度为 $n$ 的排列包含 $1\sim n$ 中的每个正整数恰好一次。

{{ s('input format') }}

输入的第一行包含一个正整数 $T\ (1 \le T \le 200)$，表示测试数据组数。

对于每组测试数据，第一行包含一个正整数 $n\ (2 \le n \le 100)$，代表目标排列长度。

接下来一行包含 $n$ 个整数 $a_1, a_2, \dots, a_n\ (-1 \le a_i \le n)$，含义见题目描述。

保证单个测试点内所有数据 $n$ 的和不超过 $400$。

{{ s('output format') }}

对于每组测试数据，输出一行一个整数，表示答案对 $10^9 + 7$ 取模的结果。

{{ self.title_sample_description() }}

对于第一组测试数据，由于两端的位置永远不会被删除，因此所有长度为 $2$ 的 $2$ 个排列均符合条件。

对于第二组测试数据，考虑排列 $p=[2,1,3]$：

- 第一轮操作时，由于 $p_2<p_1$，且 $p_2<p_3$，因此位置 $2$ 被删除，排列变为 $[2,-,3]$；
- 第二轮及以后操作，由于两端的位置永远不会被删除，因此排列不再发生改变。

数组 $b=[0,1,0]$，符合条件。另一个符合条件的排列为 $[3,1,2]$。

对于第三组测试数据，以下为两个符合条件的排列：

- $p=[4,1,3,2]$ 时 $b=[0,1,0,0]$；
- $p=[3,1,2,4]$ 时 $b=[0,1,2,0]$。
