{{ s('description') }}

小 L 与 小 S 是一对关系非常要好的朋友。

有一天，小 L 看到了一个长度为 $n$ 的，只包含字符 `0` 与 `1` 的字符串 $P$，她需要将 $P$ 的内容传递给小 S。

小 L 有一台打字机，这台打字机可以向小 S 发送一个只包含字符 `0` 与 `1` 的字符串 $Q$，但由于打字机年久失修，传递的字符串 $Q$ 有着以下两个限制：

1. $Q$ 的长度不能大于 $\lfloor\frac 32n\rfloor$，其中 $\lfloor x\rfloor$ 代表不大于 $x$ 的最大整数。
2. $Q$ 中任何连续的三个字符不能全部相同，即不存在正整数 $1\le i \le m-2$，使得 $Q_i=Q_{i+1}=Q_{i+2}$，其中 $m$ 为 $Q$ 的长度。字符串的下标从 $1$ 开始。 

请帮助小 L 与小 S 制定传递策略，使得小 S 可以根据小 L 发送的字符串 $Q$ 推断出小 L 看到的字符串 $P$。

{{ s('实现细节') }}

你的程序将会**独立运行两次**，其中第一次将扮演小 L，需要根据看到的字符串 $P$ 向小 S 传递一个符合限制的字符串 $Q$；第二次将扮演小 S，需要根据收到的字符串 $Q$ 推断出小 L 看到的字符串 $P$。交互器将在你的程序之间传递信息。

在第一次运行中，你的程序会首先收到字符串 $P$ 的长度与内容， 然后你的程序需要输出字符串 $Q$ 的长度与内容，从而向第二次运行传递信息。

在第二次运行中，你的程序会从交互器收到来自第一次运行的信息，即字符串 $Q$ 的长度与内容。你需要根据这些信息推断出其对应字符串 $P$ 的内容。

{{ s('输入输出格式') }}

每个测试点中包含多组测试数据。输入的第一行包含两个正整数 $T,r$ $(1\le T \le 2\times 10^4, r\in \{1,2\})$，表示数据组数与阶段编号。对于每组测试数据：

- 若 $r=1$，则输入格式如下：

  - 第一行输入一个正整数 $n$ $(1\le n \le 5\times 10^5)$，表示字符串 $P$ 的长度。
  - 第二行输入一个长度为 $n$ 的，仅包含字符 `0` 与 `1` 的字符串 $P$。

  你需要按如下格式输出两行：

  - 第一行包含一个正整数 $m$ $(1\le m \le \lfloor\frac 32n\rfloor)$，代表字符串 $Q$ 的长度。
  - 第二行包含一个长度为 $m$ 的，仅包含字符 `0` 与 `1` 的字符串 $Q$，其中任何连续的三个字符不能全部相同。

  对于每一组测试数据，你必须输出字符串 $Q$ 并刷新标准输出缓冲区后，才能继续输入下一组测试数据。

  保证单个测试点内所有测试数据 $n$ 的和不超过 $5\times 10^5$。

- 若 $r=2$，则输入格式如下：

  - 第一行输入一个正整数 $m$，表示字符串 $Q$ 的长度。
  - 第二行输入一个长度为 $m$ 的，仅包含字符 `0` 与 `1` 的字符串 $Q$。

  你需要按如下格式输出两行：

  - 第一行包含一个正整数 $n$，代表字符串 $P$ 的长度。
  - 第二行包含一个长度为 $n$ 的，仅包含字符 `0` 与 `1` 的字符串 $P$，代表小 L 看到的字符串。

  对于每一组测试数据，你必须输出字符串 $P$ 并刷新标准输出缓冲区后，才能继续输入下一组测试数据，并且单个测试点内测试数据输入的先后顺序相较第一次运行时**可能不同**。

{{ s('样例') }}

第一次运行时，输入如下：

```text
3 1
1
0
3
111
6
001100
```

小 L 可以按如下输出发送字符串：

```text
1
0
4
0010
7
0101010
```

根据上述输出，第二次运行时，一种可能的输入如下：

```text
3 2
4
0010
7
0101010
1
0
```

通过心灵感应，小 S 推断出三组测试数据的 $P$，按如下格式输出：

```text
3
111
6
001100
1
0
```

注意，在第一次运行的第二组测试数据中，小 L 不能按如下方式发送字符串 $Q$：

```text
5
10101
```

$Q$ 的长度 $m=5$ 大于 $\lfloor \frac 32n\rfloor=4$，违反限制 1。

```text
4
1110
```

$Q$ 中前三个字符 $Q_1,Q_2,Q_3$ 均为 `1`，违反限制 2。
